# doxygen-style-revamped

A Qt 6 docs-style theme package for Doxygen 1.17. Replaces doxygen-awesome-css with
a self-contained chrome (layout, typography, light + dark palette, sidebar, breadcrumb,
member tables, code blocks) plus semantic badges and a vanilla dark-mode toggle.

Target look: the Qt 6 reference docs (light default, Qt-green section accents, blue links,
two-column member tables, left class-list sidebar, breadcrumb). Doxygen 1.17 ships no jQuery,
so every script here is vanilla DOM, guarded by `DOMContentLoaded`.

## Files

| File | Owner | Purpose |
| --- | --- | --- |
| `doxygen-style-revamped-theme.css` | chrome | Layout, typography, light + dark palette `:root`, sidebar, breadcrumb, member tables, code blocks, dark-toggle button styling |
| `doxygen-style-revamped-darkmode-toggle.js` | chrome | Vanilla light/dark toggle; renders a button into the search box area |
| `fonts/` | chrome | Font binaries + per-font `@font-face` CSS (NotoSans body, FantasqueSansMono code) |
| `doxygen-style-revamped-badges.css` | badges | Badge + mlabel + code-punct + inherited-toggle styling (consumes the palette vars below) |
| `doxygen-style-revamped-badges.js` | badges | const de-dup + public badge + type-colored mlabels + `f(x)` superscript on inline references to member functions |
| `doxygen-style-revamped-code-punct.js` | badges | Code-fragment punctuation coloring |
| `doxygen-style-revamped-inherited-toggle.js` | badges | Collapsible inherited-member sections |
| `header.html` | chrome | Doxygen `HTML_HEADER`: title area + `$relpath^` script/stylesheet tags, and the anti-flash dark-mode head snippet. Wires every theme JS in load order |
| `footer.html` | chrome | Doxygen `HTML_FOOTER`: navpath/breadcrumb + "generated by" line |
| `layout.xml` | chrome | Doxygen `LAYOUT_FILE`: navindex tab order/titles and per-page member section layout |
| `README.md` | chrome | This file |

## Doxyfile wiring

Point Doxygen at the three structural files in this directory (paths relative to the
directory doxygen runs from, i.e. the repo root):

```
HTML_HEADER            = doxygen-style-revamped/header.html
HTML_FOOTER            = doxygen-style-revamped/footer.html
LAYOUT_FILE            = doxygen-style-revamped/layout.xml
```

Also exclude this directory from parsed input so the `.html`/`.xml` are treated as
theme assets, not documented sources:

```
EXCLUDE                = doxygen-style-revamped \
                         ...
```

The CSS and JS assets load via `HTML_EXTRA_STYLESHEET` / `HTML_EXTRA_FILES` - see the
next section for load order. `header.html` references each script through Doxygen's
`$relpath^` marker, which resolves to the copied-into-`docs/html` asset.

## How the build consumes it

The Doxygen build wires this package as a submodule. Load order matters:

CSS (HTML_EXTRA_STYLESHEET):

1. `doxygen-style-revamped-theme.css`
2. `doxygen-style-revamped-badges.css`
3. per-font CSS under `fonts/`

JS (header, HTML_EXTRA_FILES), in order:

1. `doxygen-style-revamped-darkmode-toggle.js`
2. `doxygen-style-revamped-badges.js`
3. `doxygen-style-revamped-code-punct.js`
4. `doxygen-style-revamped-inherited-toggle.js`

Font `url()` paths resolve to `fonts/<name>.<ext>` relative to the docs root, where the
build copies the `fonts/` directory.

## Dark-mode contract

- The toggle target is the `<html>` element. Dark mode = `<html class="dark-mode">`; light = the class absent.
- Style under `html.dark-mode` for dark overrides.
- The choice persists in `localStorage['doxygen-darkmode']` as `'dark'` or `'light'`.
- On first load with no saved choice, the mode follows `prefers-color-scheme`.
- `doxygen-style-revamped-darkmode-toggle.js` applies the class as early as possible (it runs in `<head>`) to reduce flash.
  The build may also inline a short head snippet reading the same key for a flash-free first paint.

## Palette variables

Defined once in `doxygen-style-revamped-theme.css :root`, overridden under `html.dark-mode`. Values are tunable;
the names are the contract. Badge styling reads the `--*-mlabel-color` set.

Chrome:

- `--pvn-accent`, `--pvn-accent-strong` - Qt green
- `--pvn-link`, `--pvn-link-hover`
- `--pvn-bg`, `--pvn-fg`, `--pvn-muted`
- `--pvn-border`, `--pvn-sidebar-bg`, `--pvn-code-bg`
- `--pvn-table-head-bg`, `--pvn-table-row-alt`

Badges (consumed by `doxygen-style-revamped-badges.css`):

- `--public-mlabel-color`, `--const-mlabel-color`, `--static-mlabel-color`
- `--protected-mlabel-color`, `--private-mlabel-color`, `--signals-mlabel-color`
- `--slots-mlabel-color`, `--noexcept-mlabel-color`, `--friends-mlabel-color`
- `--const-color`, `--fragment-punct`
